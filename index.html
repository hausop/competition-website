❰ 報名程序說明 ❱

(一) 報名資格：

全國各大專院校金融、財金、保險相關科系或對於保險規劃有興趣之在校學生皆可組隊參與，初賽參與各團隊人數3人以上，最多6人。

(二) 報名方式：

自大賽官網下載或大賽簡章中填寫約定書，於報名截止日前完成線上報名程序且將約定書上傳官網，完成報名程序。

(三) 說明會、比賽報名日期：

2026年09月07日(一)起至2026年12月24日(四)。

(四) 收件截止日期：

2026年12月24日(四)12:00 止。

(五) 完成線上報名程序且約定書得隨同初賽資料傳送至主辦單位，視同報名完成。

(六) 報名費用：無需費用。

❰ 初賽程序說明 ❱

(一) 業界老師提供參賽隊伍諮商與輔導並協助進行初賽報告。

  1. 可向主辦單位申請業界老師。
  2. 可自行尋找曾經參與比賽之在校或畢業的學長姐擔任業界老師。
  3. 自行尋找現職保險業務人員擔任業界老師。
  4. 健診軟體可由參賽隊伍自由選擇使用。

(二) 比賽內容：

依據拜訪的家庭狀況進行保單健診並規劃保單，規劃時需詳述被保險人家庭狀況，包含以下：

  1. 成員
  2. 收支
  3. 情境
  4. 目前保單狀況
  5. 未來保單規劃
  6. 規劃目的與方向總結

(三) 保險規劃書範本：

報名隊伍可自大賽官網下載保險規劃書範本，範本僅供參考非初賽作品必備形式。

(四) 保單健診規劃報告：

拜訪家庭並進行家庭成員保單健診，每隊須取得同家庭至少三位以上被保險人的保單資料進行保單健診。針對受訪家庭保單健診結果，依其需求擬定完整的家庭保險建議書，進行保險商品查詢與比較，並就保險規劃之目的與方向簡述。本賽事不蒐集利用受訪家庭個資，比賽報告內要被保險人姓名皆以化名處理。

(五) 初賽報告收件：

作品資料僅須註明隊伍名稱及學生姓名，不可揭露學校、系所、指導老師與業師等資訊，包含隊伍取名，並於初賽收件截止日2026年12月24日(四)12:00前將參賽保險規劃書以PDF檔格式自官網上傳給主辦單位，完成初賽程序。初賽報告總頁數以50頁(含附件)為上限

(六) 初賽結果：

  1. 入圍公告，各區依初審結果取前十名隊伍公告為優等隊伍，且取數名隊伍入圍參賽全國總決賽，惟參賽隊伍代表需簽回【參與總決賽確認函】，若無回覆，取消參賽資格，由次一名次隊伍依序遞補入圍。優等獎之獲獎隊伍數，依參賽隊伍數酌與調整之。
  2. 全國總決賽三區入圍隊伍數，依實際繳交報告隊伍數比例分配，總參賽隊伍為12隊。
  3. 入圍公告暨優等組頒獎典禮地點及時間：
    1. 北區：2027/01/11（一） 銘傳大學 (111台北市士林區基河路130號)
    2. 中區：2027/01/12（二） 朝陽科技大學 (413臺中市霧峰區吉峰東路168號)
    3. 南區：2027/01/13（三） 樹德科技大學 (824高雄市燕巢區橫山路59號)
  4. 為鼓勵認真完成報告且完善者之隊伍，頒布佳作獎項。

(七) 報名且完成初賽報告隊伍每位皆可獲得【參賽證明】。

(八) 評審及評分事宜：

  1. 初賽評審：由主辦學校邀請學者老師三位擔任書面評審，跨區評分。
  2. 評審規則：
    1. 初賽評審（3位）於入圍審核截止日前完成初賽評分。
    2. 依據初賽評分標準評分。
    3. 各評審完成評分並各自排出初賽名次後，再以3位評審各自的排序補上100分遞減分數後取出平均數，計算出總分數。
    4. 北、中、南三區各四隊入圍全國總決賽，初賽如遇同分，視比重最高之評分項目，分數較高者為入圍隊伍。
  3. 主辦單位報告規範：
    1. 健診報告須取得同家庭至少三位以上被保險人的保單資料進行保單健診。
    2. 初賽報告總頁數以50頁(含附件)為上限。
    3. 報告上傳檔案格式：PDF。
    4. 簡報請將要被保險人姓名皆以化名處理。
    5. 作品資料一律請勿揭露學校、系所、指導老師與業師等資訊(含隊伍取名)。
  4. 初賽評分標準：
